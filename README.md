# DataLab — Data Analysis Dashboard

A Python-based data analysis dashboard built with **Streamlit, Pandas, and Plotly**. DataLab allows users to upload datasets, explore their data, create interactive visualisations, and generate useful insights.

## Features

- **Dataset Upload:** Import CSV and Excel files.
- **Sample Dataset:** Explore the dashboard using built-in sample sales data.
- **Data Filtering:** Filter datasets to focus on specific information.
- **Interactive Visualisations:** Generate bar charts, line charts, scatter plots, histograms, box plots, pie charts, and correlation heatmaps.
- **Automatic Analysis:** View useful summaries and statistics about your data.
- **Data Export:** Download analysed data as CSV files.

## Technologies Used

- Python
- Streamlit
- Pandas
- Plotly
- OpenPyXL

## Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/LegendaryGuy123454/DataLab.git
   ```

2. Enter the project folder:

   ```bash
   cd DataLab
   ```

3. Install the required libraries:

   ```bash
   python3 -m pip install -r requirements.txt
   ``
